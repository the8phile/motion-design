# Kopia brand assets

- `kopia-logo-blue.png`, `kopia-logo-white.png`, `kopia-mark-blue.png`, `kopia-mark-white.png` — transparent cut-outs
  of the official JPGs (`python3 scripts/brand_cutouts.py`). Replace with exports of the official SVGs when available.
